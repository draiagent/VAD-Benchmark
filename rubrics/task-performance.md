# Task Performance Rubric

Task-specific acceptance criteria 由各 Task Pack 定義；本文件只統一跨任務的評分規則。

## Acceptance Item

每項標記：`pass / fail / not_applicable`。Completion Rate 只用 applicable items 計算。

## Error Severity

- **Critical (×5)**：成果無法使用、必要輸出缺失、關鍵資料錯誤、違反不可妥協限制。
- **Major (×3)**：顯著影響品質或主要驗收，但成果仍可局部使用。
- **Minor (×1)**：局部格式、文字或細節問題，不影響核心功能。

同一問題不可重複計入多個 severity，除非它造成可區分的獨立錯誤。

## First-Pass Yield

第一次正式交付即通過所有 required acceptance items，且沒有 Critical / Major error，才算 first-pass pass。

## Blind Scoring

盲評檔案應移除 condition 與模型品牌資訊。評分者只看到 task contract 與成果。評分分歧保留原始紀錄，再依 preregistered adjudication procedure 處理。
