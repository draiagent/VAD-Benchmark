# PILOT-WEB-001｜Northstar Learning Lab

本專案為完全虛構的 Benchmark 素材。

## Project

Northstar Learning Lab 是一個企業內部學習計畫，提供 AI 工作流程入門課程與任務設計工作坊。

## Audience

中小企業主管、專案經理、部門種子學員。

## Main Message

把複雜 AI 觀念轉成可理解、可操作、可驗收的工作方法。

## Services

1. AI Task Design Workshop：2 小時入門工作坊。
2. Visual Workflow Lab：以流程圖與任務卡拆解工作。
3. Team Pilot Sprint：小型團隊以一週完成一個 AI 工作流程 Pilot。

## Page Requirements

單頁響應式網站，至少包含：

- Hero
- About
- Services
- How It Works
- FAQ
- Contact / CTA

## CTA

主要 CTA：「預約 Pilot 說明」

本 Benchmark 不提供真實聯絡方式，因此 CTA 可使用 `#contact` 錨點，不得自行捏造 email、電話或地址。

## FAQ

- 需要會寫程式嗎？不需要，重點是先定義工作。
- 課程適合哪些人？企業主管、專案人員與內部 AI 種子。
- 會教特定 AI 模型嗎？會示範多模型，但方法應盡量保持模型中立。

## Visual Direction

清楚、專業、現代、mobile-first；可使用卡片與簡單線性圖示。不得抓取未授權圖片或自創真實客戶案例。
